# AnimeWorldApp (DEPRECATA)

App Non ufficiale di AnimeWorld

Guarda anime da AnimeWorld.tv senza pubblicità.

# Features
- Download degli episodi
- Picture in Picture (PiP)  
- Cast (incoming)  
- Preferiti
- Ripresa episodio da ultimo Timestamp
- No Ads
